# Interview-AI 🤖

### AI-Powered Interview Preparation Platform

Interview-AI is an AI-powered interview preparation platform designed to help students and job seekers prepare for interviews with confidence. It provides an interactive environment to practice interviews, improve communication skills, and analyze performance through AI-powered feedback.

## 🚀 Features

- AI-powered mock interview preparation
- User authentication and account management
- Personalized interview practice
- Interview performance reports
- AI-generated feedback and suggestions
- Modern and responsive user interface

## 🛠️ Tech Stack

**Frontend**
- React.js
- JavaScript
- SCSS / CSS

**Backend**
- Node.js
- Express.js
- MongoDB

**AI Integration**
- Generative AI

## ⚙️ Installation & Setup

1. Clone the repository:

```bash
git clone https://github.com/nitinmaurya0715-star/interview-ai.git
```

2. Navigate to the project:

```bash
cd interview-ai
```

3. Install backend dependencies:

```bash
cd Backend
npm install
```

4. Configure your environment variables in `Backend/.env`.

5. Start the backend using the appropriate script from `Backend/package.json`.

6. Open another terminal and install frontend dependencies:

```bash
cd Frontend
npm install
```

7. Start the frontend using the appropriate script from `Frontend/package.json`.
